# EvoSkill AI

### AI-Powered Personalized Career & Learning Platform

EvoSkill AI is an AI-powered platform designed to help learners discover suitable career paths, identify skill gaps, and build personalized learning roadmaps.

The platform transforms career goals into structured learning journeys with skills, projects, resources, progress tracking, and AI assistance.

---

## ✨ Features

- 🤖 **AI Career Assessment**
  - Understands interests, strengths, goals, and preferences.

- 🧭 **Personalized Career Roadmaps**
  - Generates structured career paths based on individual profiles.

- 📚 **Personalized Learning Plans**
  - Breaks career goals into manageable learning steps.

- 🚀 **Project Recommendations**
  - Suggests practical projects to build real-world skills.

- 📊 **Career & Market Insights**
  - Helps learners understand relevant skills and career opportunities.

- 🧑‍🏫 **AI Study Buddy**
  - Provides interactive AI assistance during the learning journey.

- ⏱️ **Focus Timer**
  - Helps learners maintain focused study sessions.

- 📈 **Progress Tracking**
  - Track learning progress, activities, notes, and streaks.

- ☁️ **Firebase Integration**
  - Authentication and cloud data storage.

- 📅 **Google Workspace Integration**
  - Export learning plans to:
    - Google Tasks
    - Google Calendar
    - Google Docs
    - Google Sheets

- 🌙 **Dark Mode**
  - Responsive interface with light and dark themes.
